## Additional findings

- `.env.example` contained values that looked like real provider credentials rather than placeholders. They have been replaced with setup placeholders in this checkout. Treat those credentials as exposed and revoke/rotate them. This audit did not inspect `.env` or print its contents.
- The application remains a local/prototype architecture: vanilla JS, FastAPI and per-user SQLite. There is no frontend production bundler, Alembic migration system, account recovery, external reminder scheduler, or full automated browser suite.
- No actual email is sent by CareerOS; generated outreach remains editable text. No external application submission is performed.
